# Site d'Annonces

Plateforme web de publication et gestion d'annonces développée avec Laravel.

## Technologies utilisées
- Laravel
- PHP
- MySQL
- HTML5 & CSS3

## Fonctionnalités
- Inscription et connexion utilisateur
- Publier une annonce
- Modifier une annonce
- Supprimer une annonce
- Liste et détail des annonces
